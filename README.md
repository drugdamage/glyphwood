An endless descent through six biomes (a graveyard forest, an ossuary, an
ashen abyss, a gallows mire, a drowned cathedral and a frostbound crypt) that
come back in a new order every time you reach the bottom, with procedural
levels, secret walls, arenas, a merchant and a boss at the end of every biome;
lanterns are your checkpoints and a small arrow always points the way, while
every kill grows your hero for good, so a few minutes or a few hours both
count. A skill tree with three seven-tier branches and either/or forks;
swords, rapiers, maces, axes, scythes, halberds, daggers, spears and katanas
you can see in the hero's hands; knives, boomerangs, chakrams, javelins and
flasks to throw; a belt of three weapons on keys 1, 2 and 3, armour you
can see on the hero and reinforce, blocks and parries, combos, dash lunges, critical hits
and bosses that stagger, several worlds you name yourself with four
difficulties, keyboard, mouse and gamepad, and seven languages.

## Install

**macOS / Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/drugdamage/glyphwood/main/install.sh | sh
```

**Windows** (PowerShell)

```powershell
irm https://raw.githubusercontent.com/drugdamage/glyphwood/main/install.ps1 | iex
```

The command installs the latest version and starts it; run it again to update.
You can also download the zip from the
[latest release](https://github.com/drugdamage/glyphwood/releases/latest).

## Run from source

1. Install [Godot 4.5](https://godotengine.org/download) or newer (the standard build, not .NET).
2. Clone this repository: `git clone https://github.com/drugdamage/glyphwood.git`
3. Open `project.godot` in Godot and press **F5**.

See [CONTRIBUTING.md](CONTRIBUTING.md) to add rooms, enemies or translations.
