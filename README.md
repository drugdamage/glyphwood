- Beyond the first 18 levels, choose shorter expeditions with mixed foes and different rewards.

## Install

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/drugdamage/glyphwood/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/drugdamage/glyphwood/main/install.ps1 | iex
```

Run it again to update.

## Run from source

Open `project.godot` in [Godot 4.5+](https://godotengine.org/download) and press **F5**.
